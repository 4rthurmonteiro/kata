# 1000 Numbers

## Description

Read a sequence of 1000 integers.

Then read another integer N. Your program must print how many times N appears among the previous 1000 integers.

The program stops when the first of the 1000 integers is -1.

## Input format

The input starts with 1000 integers, which you must include in the count. After them comes an integer N, and you must count the K times it appeared among those 1000 integers. If the next number read is -1, the input ends. If it isn't, read the other 999 integers, and the process repeats.

## Output format

For each batch of 1000 integers, print the following sentence:

`N appeared K times`
