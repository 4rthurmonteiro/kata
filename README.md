# Code Katas

A collection of code katas I practice regularly to keep my brain sharp
and my fundamentals solid. All solutions are written in **Flutter/Dart**.

## The rule: no LLMs

Every line of code in this repository is written by me, without the help
of ChatGPT, Copilot, Claude, or any other AI tool. No autocomplete
suggestions, no generated code, no "explain this to me."

AI tools are part of my daily work, and that's exactly why this repository
exists. The goal here is to exercise my own reasoning: to struggle a little,
think through the problem, and build the solution step by step.

## What is a kata?

The term comes from martial arts: a kata is a choreographed set of movements
practiced over and over until they become second nature. In software, a kata
is a small, well-known problem solved repeatedly. The point isn't to find
the answer, but to refine *how* you get there.

As Robert C. Martin (Uncle Bob) describes in *The Clean Coder*, katas are a
way for professional developers to warm up before work, just like musicians
practice scales.

## How I practice

- **Test-Driven Development**: every solution is built through the
  red → green → refactor cycle.
- **Small steps**: the commit history shows the progression, one test at a time.
- **Repetition**: the same kata may appear more than once as I revisit it
  to make it cleaner and faster.
- **Constraints**: sometimes I add rules (no `if` statements, no mouse,
  only immutable data) to push myself out of habits.
